# Easier recording names and controls

- Rename a recording with the visible Rename button beside its title, by right-clicking it in the list, or by pressing Return on a selected recording. Enter saves, Escape cancels, and an empty name restores the date.
- Pause and resume recordings from the menu bar. The recording's status takes priority over the idle dictation hint, and starting or saving no longer offers an ineffective Start button.
- A requested pause no longer polls stopped audio sources or triggers missing-audio warnings. Resuming gives both channels time to deliver sound again.
- Updating or renaming recordings no longer scans every audio file to calculate an unused library-size total. Individual recording sizes remain available in Recording Details.
- Clearer microphone, shortcut and transcript explanations across Recordings, Settings and first-time setup.
