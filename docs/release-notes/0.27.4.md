# OpenRamble 0.27.4

Recordings now play in both ears. Your microphone and the other side are mixed
to the center during playback and audio export, including for existing
recordings. The original source tracks remain separate for transcription.
Playback also resumes correctly if the audio device changes while paused.

The default recording shortcut is now **Control–Command–R**. Press it again to
finish. **Command–R** opens Recordings while OpenRamble is active. Custom
recording shortcuts are preserved.

Opening Recordings brings the library to the front even when Settings is
already open. Its command remains visible in the main app menu.
